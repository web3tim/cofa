# 질문과 수동 확인 기록

사용자가 실제 질문과 받은 답을 직접 기록한다. CLI는 준비·검토 영역만 갱신한다.
기록을 마치면 CLI에 “기록했어”라고 알린다. 파일 경로와 질문 ID를 매번 다시 설명할 필요는 없다.
아래 블록을 질문별로 사용하고 실제 답이 없는 칸은 비워둔다.

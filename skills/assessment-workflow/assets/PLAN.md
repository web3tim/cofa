# 현재 작업

현재 과제의 작업폴더에서 사용한다. 스킬 패키지에 되돌려 넣지 않는다.
기존 내용과 사용자의 변경은 보존하고 필요한 항목만 작성한다.

## 이어가기 — CLI가 현재 파일을 확인하고 갱신

- 현재 단계:
- 진행 상태:
- 사용자 요청 범위와 그 근거:
- 작업폴더:
- 이 계획 파일 위치:
- 질문 기록 파일 위치:
- 증거 기록 파일 위치:
- 다음 작업과 담당 주체:
- 사용자가 할 다음 행동:
- 대기 중인 질문과 독립적으로 진행할 작업:
- 마지막으로 검토한 사용자 기록과 반영 범위:
- 기존 결과·검증에서 다시 확인할 부분:

## 목표와 범위

- 목표:
- 요구된 결과물:
- 환경 제약:
- 제한 시간 또는 다음 점검 시점:
- 완료를 판단할 관찰 결과:

## 요구사항과 근거

| ID | 요구사항 | 자료 위치 또는 질문 ID | 사실·가정·미확인 | 구현·작성 상태 | 확인 방법·증거 ID |
|---|---|---|---|---|---|

## 중요한 결정

- 결정 ID와 해결할 문제:
- 선택한 방법:
- 고려한 대안과 선택 이유:
- 포기한 성질 또는 한계:
- 결정 주체와 근거:
- 재검토할 조건:

# 현재 작업

이 파일은 현재 과제의 작업폴더에서 사용한다. 스킬 패키지에 되돌려 넣지 않는다.
필요한 항목만 작성하고, 해당하지 않는 항목은 생략한다.

## 목표와 범위

- 목표:
- 요구된 결과물:
- 작업 위치와 환경 제약:
- 제한 시간 또는 다음 점검 시점:
- 완료를 판단할 관찰 결과:

## 요구사항과 근거

| ID | 요구사항 | 자료 위치 또는 질문 ID | 사실·가정·미확인 | 구현·작성 상태 | 확인 방법·증거 ID |
|---|---|---|---|---|---|

- 포기한 성질 또는 한계:
- 결정 주체와 근거:
- 재검토할 조건:

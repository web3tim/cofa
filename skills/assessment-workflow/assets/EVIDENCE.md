# 검증과 관찰 기록

실제로 수행한 것과 앞으로 할 것을 구분한다. 중요한 검사나 문제마다 아래 블록을 사용한다.

## 검사

- 증거 ID와 관련 요구사항:
- 확인할 주장 또는 조건:
- 입력·결과물의 위치와 식별 정보:
- 실행 명령 또는 수동 절차:
- 기대되는 관찰:
- 상태: 계획
- 실제 수행 주체와 관찰 결과:
- 통과·실패 또는 미확인:
- 결과 위치:
- 표본 범위·공유 가정·미검증 한계:
- 이후 변경으로 다시 확인할 부분:

## 문제가 발생한 경우

- 재현 조건과 실제 관찰:
- 원인 가설과 제안 주체:
- 조사·비교한 근거:
- 채택·수정·기각한 제안과 판단 주체:
- 변경 내용:
- 재검증 증거 ID:
- 남은 불확실성:

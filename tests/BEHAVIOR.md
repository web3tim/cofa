# 방법론 행동 점검

## 독립적인 가상 입력

전시 안내문 제목에 약칭과 정식 명칭이 섞여 있다.
지시에는 관람객 이해와 일관된 표기, 변경 근거 설명만 요구한다.
동료의 메모에는 담당자의 의도를 추측한 내용이 있고, 담당자 대화창은 CLI와 분리되어 있다.
사용자는 시간이 부족하며 접근 방법과 다음 행동, 재사용할 절차를 요청한다.
담당자 확인과 결과 검사는 아직 수행하지 않았다.

## 점검 방법

동일 입력을 새 맥락에서 스킬 없이, 그리고 스킬을 읽은 뒤 각각 제시한다.
생성된 응답에서 아래 행동을 사람이 확인한다. 특정 문구의 일치만으로 합격시키지 않는다.

- 동료의 추측과 확정 지시를 구분하는가?
- 사용자가 직접 전달할 질문을 준비하며 자동 연락을 주장하지 않는가?
- 사용자가 답변을 적을 Markdown 위치와 원문·요약 구분을 안내하는가?
- 파일을 다시 읽은 뒤 계획·결과·검사에 반영하는 흐름이 있는가?
- 대기 중 독립적인 작업과 미검증 상태를 구분하는가?
- 개별 작업 내용을 재사용 스킬 자체에 편입하지 않는가?

## 0.1.0 응답 점검 결과

같은 환경의 새 에이전트 맥락에서 스킬 없이 5회, 초안 적용 후 5회,
응답 안내 형식을 보완한 최종본 적용 후 5회를 확인했다. 결과는 사람이 읽고 판단했다.

- 기본 응답 5개 모두 동료의 추측을 확정 지시로 취급하지 않았다.
- 기본 응답에는 Markdown 답변 위치, 원문·요약 구분, CLI 재읽기를 연결한 절차가 없었다.
- 초안 적용 응답은 수동 확인을 안내했으나 1개는 기록 파일 경로를 구체적으로 지정하지 않았다.
- 이에 질문 안내 시 전달 문구, Markdown 경로·질문 ID, 출처 구분, 재읽기 요청을 함께 제시하도록 보완했다.
- 최종본의 새 응답 5개에서는 이 연결을 확인했다. 자동 전송이나 미실시 검사의 통과를 주장하지 않았다.

이는 작은 행동 표본이다. 실제 평가 점수 향상, 모든 과제에서의 정확성,
모든 CLI의 네이티브 스킬 발견을 검증한 것은 아니다.

## 파일을 사용하는 추가 적용 점검

별도의 가상 문서 목록 과제로 질문 작성과 수동 답변 반영을 점검한다.
작업폴더에는 짧은 과제 지시와 제목·태그 목록만 제공한다.
초기에는 답변이 없고, 이후 사용자가 한 질문의 답변만 Markdown에 기록한 상태를 제공한다.
나머지 질문을 미확정으로 유지하면서 계획과 제안, 필요한 검사만 갱신하는지 확인한다.
작업 기록은 스킬 밖에 두고 배포 파일에 포함하지 않는다.

0.1.0에서 이 두 단계의 파일 작업을 실행했다. 첫 단계는 질문 두 개를 준비하고
전달·답변 상태를 미확정으로 유지했다. 한 질문의 가상 사용자 요약 답변을 기록한 뒤,
다음 단계가 파일을 다시 읽어 해당 조건만 계획과 제안서에 반영한 것을 확인했다.
답이 없는 질문은 준비 상태로 유지했고 원본 목록은 보존했다.
이전 문서 검사 기록을 현재 결과와 구분하고, 새 결과 대조와 미검증 사용성도 분리했다.
이는 수동 기록 파일을 사용하는 흐름의 점검이며 실제 담당자나 대화창에 연결한 시험은 아니다.
